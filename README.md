# Ejam Kopā (Let's Go Together)

A non-profit platform for finding people to do things with in Latvia — a gym buddy, a book club, a choir looking for singers. Create a group, be found, let people join, talk, then meet in real life.

Live: https://ejam.lumm.eu

- **Values, voice, behaviour and design (the Handbook):** [docs/handbook/](docs/handbook/README.md)
- **What's being worked on now:** [docs/execution_handoff.md](docs/execution_handoff.md)
- **Setup, commands and code rules:** [AGENTS.md](AGENTS.md)

Built with Next.js 16, TypeScript, Tailwind CSS v4, PostgreSQL + Prisma, Auth.js, next-intl (LV/EN) and Soketi. Pushes to `main` deploy automatically.
