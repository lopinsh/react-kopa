# R27 spec · Group head and layout

Spec for R27, written 27 Oct 2026 against `main` at `56244f8` (R26 live). Source: the owner-approved plan of 27 Oct (`r27-plan.md`, applied as written, no added scope). Illustration: [`R27-mockup.html`](R27-mockup.html) (open it in a browser; the toolbar switches role, private, one section, no photo, tone and dark). It is intent, not a pixel spec: build it fluid from 360 to 1920 (AGENTS.md "UI & styling", design.md "Fluid between the drawings"). Its **photo row, gallery, lightbox arrows and "Pievienot attēlus"** are section pictures, which are **R28** (next release), not R27.

Rules touched: [AR-06](../redesign.html#AR-06) (colour means category), [AR-47](../redesign.html#AR-47) / [AR-48](../redesign.html#AR-48) (group page desktop / phones), [AR-50](../redesign.html#AR-50) (Informācija), [AR-51](../redesign.html#AR-51) (action rows), [AR-46](../redesign.html#AR-46) (pending state), [AR-60](../redesign.html#AR-60) (own area shares `FrameColumns`), [AR-70](../redesign.html#AR-70) (group image, already superseded by C5), build-plan C5 and R17. The ledger (`scripts/redesign/gen.mjs`) is history: no new AR id, no ledger edit. The handbook carries the new rules (section 8).

**What changes, in one paragraph.** The 96 px tinted `GroupBanner` becomes a **head on the page grid**: a solid category-tone **info tile** over the menu and content columns, and on Informācija the **group picture as a tile over the side column** (a 3:1 strip that expands on phones). Other pages show the same tile, compact. The side column is reordered (next meeting, latest news, members with links) and starts level with the first section text. Between 768 and 1023 px the pages column moves into ☰ in the tile and the sticky bar shows, as on phones.

**Size and split.** About 24 files, too many for one build of about 80 tool calls. Two builds, each reviewed and pushed on its own; R27-2 starts after R27-1 is pushed. All i18n keys land in R27-1, so R27-2 does not touch `messages/*.json`.

## Invariants (the reviewer checks each)

1. **Every feature survives.** Each row of the preservation table (section 1) is an acceptance check. Nothing a viewer can do today disappears.
2. **Taxonomy Law.** `--accent` stays server-set in the layout's `<style>` (`layout.tsx:36`). The tile reads `--accent`/`--on-cat`; no tone or image URL is resolved on the client or put in `<style>`. The picture is an `<Image>`.
3. **Context Law.** `GroupHead`, the role button and the picture read `useGroupContext()`. The only new context-like input is the picture and credit, passed from the layout as props to the head row (as `GroupAside` gets them today); no `userRole` prop drilling.
4. **Contrast.** Title and `text-meta` on the tile reach 4.5:1 on all 15 tones in light and dark (mockup "Kontrasts" table: light min Hobiji 5.2, dark 7.7-8.0). No opacity or muted mix on tile text; hierarchy comes from size and weight. Admin-set tones go through the existing `lib/theme/contrast.ts` gate.
5. **`data-ui="group-banner"` stays** on the tile (`UI.groupBanner`, `lib/constants/index.ts:184`): `GroupStickyBar` watches it.
6. **Unchanged:** `InfoSections` behaviour (sticky tabs, scroll-spy, `#part-`, `?part=`), `FallbackLangLabel`, `HiddenGroupBanner`, `AdminGroupBridge`, `GroupDialogsProvider`, `AnnouncementsLive`, `lib/group-pages.ts` visibility, the own area (`(me)` layout) at every width.
7. **No migration, no schema change.** `--banner-mix` is a CSS variable only, so it is removed outright (no expand/contract needed).
8. **Constants Law.** Any new static list (none expected) goes to `lib/constants/`. New `data-ui` names (picture strip) go in `UI`.

## 0. Motivation and design alignment

- **Handbook values: the group's own content starts near the top** (design.md line 25). The head stays one row; the picture moves from a 16:9 block in the aside to a tile beside the info, so Informācija text starts higher on desktop and the phone strip is 3:1, not 16:9.
- **Colour means category (AR-06).** The tile is the one solid tone area of the page, in every look; buttons stay the site colour, except the tile's light pill (a named exception, section 8).
- **Reuse.** `Button` (new variant, not a new component), `IconButton`, `Modal`, `PictureBox`, `BannerCredit`, `GroupPagesDrawer`, `PendingState`, `CategoryIcon`, `CategoryLine`, `FrameColumns`, `AsideSlot`. `GroupBanner.tsx` is replaced, not kept beside the new head.

## 5. Columns, aside and sections (R27-2)

**Pages column from 1024 for groups.** `FrameColumns.tsx` gets a prop `navFrom?: 'md' | 'lg'` (default `'md'`, so the own area is untouched). With `'lg'` the grid is one column below 1024 and `lg:grid-cols-[190px_minmax(0,1fr)]` (+ aside) from 1024. `GroupPagesNav` `side` takes the same breakpoint (`hidden lg:block`); pass it through a `from` prop rather than duplicating the component. `GroupPagesDrawer` button: `md:hidden` -> `lg:hidden`. `GroupStickyBar`: `md:hidden` -> `lg:hidden`, and `layout.tsx:36` `--sticky-bar` media query `max-width:767px` -> `max-width:1023px` (the `PartTabs` sticky top reads it, `PartTabs.tsx:33`). `GroupHeadRow` follows: at 768-1023 the tile spans the whole content width (no menu column beside it).

**Aside order** (`GroupAside.tsx`): next meeting, latest news, members box, then nothing else. The external links (`GroupSocialLinks`) move inside the members box under the faces and count (mockup `who()`, line 275). Latest news shows on Informācija only; next meeting on Informācija shows in the aside only from 1024. Both conditions are segment-based and the aside is a server component: add a tiny client `components/groups/frame/SegmentGate.tsx` (`show: 'info' | 'other'`, `className?`), and wrap `LatestAnnouncement` in `show="info"` and the aside's `NextMeetingBox` in a gate that adds `hidden lg:block` on Informācija only. Accepted cost: latest news is still fetched on other pages (one `findFirst`).
- Next meeting: description clamped to 1 line (`line-clamp-1`) in `NextMeetingRow`, which also serves the board, so pass a `clamp` prop instead of changing the default.
- Latest news: title, 1-line excerpt, "author · time ago", "Visi jaunumi" (`LatestAnnouncement` already has `clamp`; make the excerpt 1 line there).
- Members box: a `Link` to `${base}/members` only when `group.isMember` (members and team). Otherwise a plain `div` with the same look (fixes today's visitor redirect).

**Alignment.** From 1024 the aside starts level with the first section's text, under the tabs divider. `AsideSlot` gets `offsetOnInfo?: boolean`; when the segment is `null` and the prop is set it adds `lg:mt-[var(--part-tabs-h)]`. The layout passes `offsetOnInfo={group.sections.length > 1}` (one section: no tabs, aside at the top).

## 12. Risks

- **Long Latvian names.** The 2-line clamp clips macrons without the `0.2em` padding trick (`BannerName.tsx:8`); keep it when restyling.
- **Next meeting rendered twice** (aside and after the first section). The fetch is already `cache()`d; the risk is visible duplication, so the gates must be exact (`lg:hidden` / `hidden lg:block`).
