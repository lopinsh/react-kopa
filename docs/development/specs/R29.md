# R29 Events for organisers

Notes cmvs6heh2, cmvs6j5lm. Rules: AR-59 (Rīkotājiem box), AR-55 (event panel), AR-49 (pages left out, badge like members), OD-06 (small confirmation for undoable steps).

1. **Popup vs page.** `EVENT_REQUEST` and `EVENT_SPOT_FREED` notifications are team work on the event page: `FULL_PAGE_NOTIFICATIONS` (lib/panel-routes.ts) makes `NotificationItem` use a plain anchor (a hard load is never intercepted). The panel shows team members "N pieteikumi → Pārvaldīt" (full-page link) when requests wait.
2. **Badge on Pasākumi** (team only): count of PENDING attendances on upcoming events of the group, from `GroupService` (`pendingEventCount` into `groupPages`). Event actions revalidate the group layout.
3. **Going list.** Per person "Rakstīt" (direct chat) and "Noņemt" (ConfirmPopover). `EventService.removeAttendee`: organiser only, GOING only, not creator/owner/admins (FORBIDDEN), not past (EVENT_PAST). The person gets `EVENT_REMOVED`. The freed place is not given to the waitlist: letting in stays the organiser's decision.
