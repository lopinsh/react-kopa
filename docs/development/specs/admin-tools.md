# Admin rīki: atsevišķi rīki, Administrācija un pārskats

## Kur esam
- Posms: lēmumi pieņemti, skices vēl nav. Nekas nav būvēts.
- Tālāk: uzzīmēt ekrānus Būvplānā, tu tos apstiprini, tad plāno izlaidumus.

## Kāpēc
Īpašnieka piezīmes, 19. nov.: "Admin panelis" skan gandrīz kā "Rīku panelis", lai gan tā ir administrācijas sadaļa. Viens kopīgs panelis trim rīkiem pēc lietošanas vairs nepatīk. Atsauksmju saraksts aizņem daudz vietas un vienmēr ir vaļā (piemēram, 136 piezīmes vienā lapā, gandrīz visas Izdarītas, daudzām "elements nav atrasts"). Ieraksti neved uz konkrēto piezīmi. Īsceļi Ziņojumi / Atsauksmes / Ieteikumi izvēlnē nav lietoti. /admin rāda tikai paslēptās grupas un moderācijas žurnālu.
