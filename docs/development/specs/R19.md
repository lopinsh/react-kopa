# R19 spec · Tēmu rādītājs (the category drawer as a quiet index)

Just-in-time spec for release R19 (not in the closed [build plan](../build-plan.md); the owner asked for it after the redesign closed), written 22 Oct 2026 against `main` at `409f450`, Next.js 16, Tailwind v4. Owner-approved drawing: [`../r19-category-sidebar.html`](../r19-category-sidebar.html) (committed with this spec). Frozen once R19 is pushed.

**Problem.** The category drawer is louder than the board it serves: fifteen coloured discs glow at rest, the chosen row is grey (its tone is not repeated though the cards are in it), there is no heading and the fold button floats alone over the search, the search adds one more horizontal line, and an empty category fades to 45 % so it looks disabled though it works. The owner wants a **rādītājs** (an index): one colour at rest, tone only where you point or where you are, the same tint-plus-dot pair as the card's tab and sticker (R18).

**Rules touched.** [AR-30](../redesign.html#AR-30) Category drawer (behaviour unchanged: all fifteen, alphabetical, icon and count, folds to a rail, the Tēma drop-down shows the same list and choice, search finds Veidi; "empty ones greyed" now means a muted name and "0", no opacity), [AR-06](../redesign.html#AR-06) Colour means category (the selected row's tint is a soft tint, the same share as the R18 tab), [AR-08](../redesign.html#AR-08) shapes and [AR-07](../redesign.html#AR-07) fonts (unchanged). Rule text: `scripts/redesign/gen.mjs` 93 and 119, **not edited here** (owner question 2). The drawing is an illustration at 1024, 1280 and a phone (AGENTS.md): build the intent, fluid between and beyond.

## Invariants (the reviewer checks each)

1. **Behaviour unchanged.** Same hrefs (`discoveryHref(params, …)`, `scroll={false}`), `aria-current` on the chosen row, `onChoose` closes the drop-down, `onSuggest` opens `CategorySuggest`, the fold cookie (`DISCOVERY_RAIL_COOKIE`) and the server-read initial `folded`, `data-ui={UI.categoryDrawer}`, the drawer hidden below `lg` and the Tēma drop-down there, alphabetical order from the service.
2. **Taxonomy Law.** Each category row sets its own `--c` from the service colour (`style={{ ['--c' as string]: c.color }}`, as `TopicButton` and the R18 card do); the tone is read only as `var(--c)` inside that row. Never `--accent`, never a colour resolved in client code (no `tint()` call, no hex in a class).
3. **Colour means category (AR-06), tone budget.** At rest every icon is `text-foreground-muted`, no disc. Tone appears in exactly four places: the icon of the hovered row, the icon of the selected row, the selected row's tint (`tab-tint`, 12 % light / 16 % dark) and the selected row's 8 px dot (rail: 6 px corner dot). Names and counts are never in tone; the hover background is the neutral `bg-tint`, never a tone. "Visas" has no tone at all: selected = `bg-tint` and a **site-colour** dot (`bg-primary`).
4. **Two text colours.** `text-foreground` for names (also selected; the choice is carried by `weight-strong` and the tint), `text-foreground-muted` for counts, an empty category's name, placeholder, the "Veidi" label and a Veid's parent path. The suggestion row is the one site-colour text (`text-primary`), as today.
5. **Empty is not disabled.** No `opacity-*` on any row; an empty category shows its muted name and "0", hovers and links like any other.
6. **One list, two places.** `CategoryList` renders the drawer column, the folded rail and the Tēma drop-down; there is no second list component. The drop-down has no "Tēmas" head and no fold button (the chip says "Tēma").
7. **Looks.** Only tokens: `rounded-item` rows, `line`/`frame` edges, `--line-active`, `--press-shift`. Drosmīgs' selected row gets the ink frame and hard shadow through one utility (section 4) that is invisible in Mierīgs and Gaisīgs; no component reads the style key.
8. **Motion.** Colour changes `transition-colors duration-quick`; the fold animates width with `duration-slow` behind `motion-safe:`; reduced motion folds at once. Icons do not move between the open column and the rail (section 3.2). Filtering while typing never animates.
9. **Defaults.** No `any`; Tailwind v4 only, no inline style except `--c`; type roles and scale spacing only (`npm run ui:check`); `lucide-react` icons only.

## 3. Structure

### 3.1 Row (R19-1, commit 2)

`CategoryRow` is a `Link` with `relative group/row flex items-center gap-3 rounded-item px-2 text-body-sm weight-medium text-foreground transition-colors duration-quick` and `min-h-11 md:min-h-9` (44 on phones, 36 from `md`; spacing table line 486). Inside, left to right:

1. **Icon.** `CategoryIcon` `size-4`, `text-foreground-muted`, `group-hover/row:text-[var(--c)]`; selected: `text-[var(--c)]`. "Visas": `LayoutGrid` `size-4`, always muted. No disc, no circle.
2. **Label.** `min-w-0 flex-1 truncate`. Veid rows: `<span className="text-foreground-muted">{parentTitle} → </span>` then the Veid's title. Matched letters via `HighlightMatch` (section 3.3). Empty (count 0) and not current: `text-foreground-muted`.
3. **Count.** `text-meta text-foreground-muted tabular-nums`, never tone, never a pill.
4. **Dot.** Only when current: `size-2 shrink-0 rounded-full bg-[var(--c)]` (Visas: `bg-primary`), after the count (`gap-3` gives the 12 px of the drawing). `aria-hidden`.

States: hover `hover:bg-tint` (neutral, also on an empty row); current `topic-chosen weight-strong` (Visas current: `bg-tint weight-strong`, no `topic-chosen`); focus `focus-visible:outline-2 focus-visible:-outline-offset-2 focus-visible:outline-primary` (or the repo's existing focus-ring utility if one exists: grep `focus-visible:` in `components/discovery/filter` and reuse that).

The rule after "Visas": `<li role="presentation" aria-hidden="true" className="mx-2 my-1 border-t border-dashed border-border" />` (a divider keeps `border-border`); rail `mx-1`. Shown only when not typing (as "Visas").

### 3.2 Drawer column, head and rail (R19-1, commit 3)

**Column.** `aside` keeps `sticky top-0 hidden h-[calc(100dvh-var(--spacing-header))] shrink-0 flex-col overflow-y-auto bg-surface lg:flex` and `w-[232px]` / `w-14`. Edge: replace `border-r border-border` with a right `line` edge (`border-r-[length:var(--line-width)] border-[color:var(--line-color)]` or a `line`-based utility; Drosmīgs then shows 2 px ink as callout 11 asks). Padding: open `px-3 pb-4`, folded `px-2`. The inner `px-1.5` wrapper goes.

**Head (open).** `mt-4 flex h-10 shrink-0 items-center justify-between gap-2 pl-2`: `<h2 id={headingId} className="text-section">` "Tēmas" (Literata via the heading role; 700 in Drosmīgs through `--heading-weight`), then the fold button as it is today (size-7, ring, `ChevronLeft`). The `aside` drops its `aria-label` and takes `aria-labelledby={headingId}`. `mt-4 h-10` puts the head on the filter line's chip row in its sticky position (the filter line is `sticky top-0 md:pt-4`); at scroll 0 the PageHead sits above the filter line, and the head stays at the top (owner question 3).

**Head (folded).** `h2` becomes `sr-only`, the button centres (`justify-center pl-0`), `ChevronRight`.

**Search.** Under the head, `ListSearch variant="quiet"` (section 3.3). Not rendered when folded (as today; a typed word is ignored while folded, as today).

**Rail rows.** `size-10 min-h-0 justify-center px-0`, list `mt-2 flex flex-col items-center gap-1`, label and count not rendered, `title="{title} · {count}"` and `aria-label={title}` as today. Current: `topic-chosen` (Visas: `bg-tint`) and the dot as `absolute right-1 top-1 size-1.5` (tone, Visas site colour).

**Icons stay put.** Open: column `px-3` (12) + row `px-2` (8) = icon at 20 px from the edge. Rail: column `px-2` (8) + (40 − 16) / 2 = 20 px. Keep both sums when changing paddings.

**Fold motion.** `motion-safe:transition-[width] motion-safe:duration-slow` on the `aside`; labels and counts unmount on fold (no fade needed: the column clips them while it narrows, `overflow-x-hidden`). Reduced motion: instant. The cookie write stays in `fold()`.

## 9. Risks

- **Selected tint contrast in dark mode.** `--tab-mix` 16 % of a light tone over a dark surface; the name is foreground, so it should pass, but check the two lightest tones (risk shared with R18's tab).
- **Highlight index.** The match is found in `foldText(title)`; if `foldText` changes the string length (for example by dropping characters), its index does not map back to the original. Fold per character (as the drawing does at line 562) inside `HighlightMatch`, or map indices; test with Latvian letters.
- **Hard shadow clipping.** The column scrolls (`overflow-y-auto`), which clips the Drosmīgs shadow of the last row and of a row at the right edge; `px-3` covers the side, give the list `pb-1`.
- **Head alignment.** `mt-4 h-10` assumes the filter line's chips are 40 px with `md:pt-4`; if `FilterButton` is a different height, match its height, not the drawing.
- **Duplicate landmark names.** The aside (labelled by "Tēmas") holds a `nav` labelled "Tēmas"; acceptable, but do not add a third.
- **`ListSearch` regressions.** Its other callers must keep `variant="line"` by default; reviewer opens Kur.
