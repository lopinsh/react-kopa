# Handbook

The Handbook is the single source of truth for what Ejam Kopā believes, how the site speaks, how it behaves and how it looks. It is read by AI agents and contributors in the repo, and shown to site admins on the live site at `/admin/handbook`.

**How to use it.** The chapters run from the deepest layer to the smallest. Every layer answers to the one above it: a button colour serves a principle, a principle serves a value. Read it before any product or UI work, and when two choices seem equal, go up a layer and let it decide. The files in this folder are the source; git is the edit history.

## Chapters

1. [Values](values.md): what we believe.
2. [Why it exists](why.md): the purpose, the core loop, typical situations, scope and how we work.
3. [Principles](principles.md): how the values become stances for the product.
4. [Voice and words](voice.md): how the site speaks.
5. [Behaviour patterns](behaviour.md): how the same situation behaves the same way everywhere.
6. [Who sees what](roles.md): what each kind of viewer sees.
7. [Design](design.md): layouts, screens, foundations, components. A draft for now.

Other documents: the plan lives in `docs/execution_handoff.md`, the code rules in `AGENTS.md`.
