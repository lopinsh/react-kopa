# Who sees what

A screen shows only what the viewer can use. Hidden, not disabled.

| On a group page | Logged out | Signed in | Pending | Member | Team |
|---|---|---|---|---|---|
| Main button | Contact → sign-in pop-up | Contact | "Pieteikums nosūtīts" + Open chat | none (role in the "…" menu) | Settings in the sidebar |
| Information, public events | yes | yes | yes | yes | yes |
| Members, Announcements, members-only events | hidden | hidden | hidden | yes | yes |
| Requests, Settings, posting | hidden | hidden | hidden | hidden | yes (Owner tab: owner only) |

**One button (owner, 2026-10-12).** A group is reached through one button, "Sazināties" (Contact). Its form has a switch, "Vēlos pievienoties grupai", on while the group takes new members, so the same message also asks to join; without the switch it is only a message. There is no separate Join button.
